# Taller de Robótica Inteligente con NVIDIA Jetson Nano

Entorno de desarrollo para aplicaciones de inteligencia artificial
en el borde (Edge AI) utilizando NVIDIA Jetson Nano.

## Objetivos

- Configuración de JetPack.
- Comunicación remota mediante SSH.
- Desarrollo de aplicaciones Python.
- Administración de contenedores Docker.
- Procesamiento de imágenes con OpenCV.
- Detección de objetos mediante YOLO26.
- Control de dispositivos mediante GPIO.
- Evaluación de rendimiento computacional.

## Plataforma

- NVIDIA Jetson Nano 4 GB.
- NVIDIA JetPack 4.x.
- Ubuntu 18.04.
- Docker y NVIDIA Container Runtime.
